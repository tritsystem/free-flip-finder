## How the sources work

- **Craigslist:** JSON endpoint
  `https://sapi.craigslist.org/web/v8/postings/search/full?batch=12-0-360-0-0&cc=US&lang=en&postal=95667&query=<term>&searchPath=zip&search_distance=50`
  (`zip` = the free section). Each item is an array: `it[0]` + `decode.minPostingId`
  = posting id; `it[1]` + `decode.minPostedDate` = posted time; `it[4]` =
  `"locIdx:descIdx~lat~lon"`; tagged sub-arrays `[4, images...]`, `[6, slug]`;
  the last element is the title. Image URL:
  `https://images.craigslist.org/<code without "3:">_600x450.jpg`. The search
  pads results with far-away "nearby" areas (Pittsburg, Reno), so a haversine
  filter keeps <= 50 mi. The body text comes from the posting page
  (`<section id="postingbody">`, attributes in `span.labl` / `span.valu`).
  Only titles that could be a candidate get a detail fetch.
- **Freecycle:** `https://www.freecycle.org/town/<Group>` has the post JSON in
  `data="{&quot;group..."` (HTML-escaped). It includes the description and
  images. Groups: PlacervilleCA, CameronParkCA, AuburnCA, FolsomCA. Only OFFER
  posts are used, and the location is the group centre. Low volume.
- **Not included (login required):** Facebook Marketplace, OfferUp, Nextdoor.
  The page footer links FB Marketplace for manual checking. Don't scrape behind
  logins. Trash Nothing has an official API but needs an API key from the user.

## Classification rules (learned the hard way, all covered by tests)

- **The item type comes from the TITLE.** The body only counts when the title
  is generic ("free stuff", "moving", "garage"...). Bodies say things like
  "bring a chain saw" or "you could put an outboard on it", and those caused
  false positives.
- `JUNK_TITLE` drops scam warnings, service ads ("Computer repair"),
  accessories (filters, covers, bags), stands, antennas and moving boxes, all
  seen in real runs.
- `EQUIP` order matters: pressure washer before washer, microwave before range
  ("over range microwave"), monitor before computer ("PC monitor"), plasma/organ
  before generic TV/music.
- Faults are **scoped by group** (a "won't drain" rule only applies to
  appliances). Any real fault outranks the word "works" ("won't drain,
  otherwise works" is a drain job).
- Refrigerant problems ("needs freon", "bad compressor") are `sealed` and count
  as parts-only: they need an EPA 608 (Environmental Protection Agency
  section 608) certified technician. "Compressor not starting" is a separate,
  cheaper fault (start relay or capacitor first).
- Craigslist bodies contain mangled apostrophes (`don�t`). `analyze()`
  normalizes them before matching.
- The score is 20 + 0.3 x (mid resale - mid fix - gas), +8 if it works,
  -5 if heavy, and -5/-10 for listings older than 5/14 days. The verdict
  thresholds are 65/45/25.
